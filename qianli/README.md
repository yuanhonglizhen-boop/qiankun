# 千里江山 · 镶嵌

把北宋王希孟《千里江山图》主峰一段，用两万块左右的镶嵌砖在浏览器里重新铺砌一遍。没有图像或视频模型，全部是 Three.js 实时渲染。

## 怎么做的

1. **分析画面**（`src/mosaic.js`）：三通道边缘检测找出山形轮廓；从上沿洪泛识别绢地；计算到轮廓的距离场。
2. **沿轮廓铺砌**（andamento）：砖先沿距离场的等值线一圈圈排，轮廓优先，再补空。每块砖顺着轮廓方向摆放。
3. **砖料**：绢地 → 金箔砖（金属、略带倾角会闪光）；石青石绿 → 玻璃砖；赭石与墨 → 石块。每类各自聚成有限几种颜色。
4. **出场顺序**：山石按卷轴方向自右向左铺，金地最后从主峰向四周漫开。红色起稿线在铺砌过半后淡出。
5. **镜头**：低角度近景跟随铺砌前沿，最后拉起到全景；之后可以自由旋转缩放。

## 配乐

`src/music.js` 用 Web Audio 实时合成，不含任何音频文件：古筝（Karplus–Strong 拨弦）弹主旋律，古琴做低音，箫铺长音，D 宫五声音阶。前 26 秒与铺砌同步（金箔砖漫开时有一段刮奏），之后转为随机散板。

## 界面

- 播放时不显示任何讲解文字；"讲解文字"开关控制题签和说明牌
- 默认正对画面居中看全景，可随时拖动；"镜头跟随"贴近铺砌前沿跟拍；"视点复位"回到全景
- 参考原画：显示截取的原画段落及其在全卷中的位置
- 叠加原画：在镶嵌画上叠出原画
- 景深开关、砖距（疏 / 中 / 密）

## 图源

`assets/segment.jpg`（截取段）与 `assets/strip.jpg`（全卷缩略）截自故宫博物院公开的数字化扫描（全卷 41783 × 1673 px），取自 [hulelan/painting](https://github.com/hulelan/painting) 重建的全分辨率图。原作为公有领域。
