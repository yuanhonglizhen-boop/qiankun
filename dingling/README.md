# 定陵玄宫立体构造

用 Three.js 写的交互式"铅笔排线"构造图，展示明十三陵定陵（万历帝与孝端、孝靖皇后合葬墓）的地宫：五座石券大殿、七道汉白玉石门、自来石、金刚墙、石隧道与砖隧道，以及地上的宝城、宝顶和明楼。

## 功能

- **工程滑杆**：开挖基坑 → 铺墁金砖 → 砌筑石券 → 安装石门 → 陈设 → 关门落自来石 → 砌金刚墙 → 隧道 → 回填 → 宝城宝顶明楼 → 着彩
- **剖切滑杆**：0–50% 竖直剖开封土，50–100% 沿中轴东侧剖开殿身
- **跟随考古队**：按 1956—1958 年发掘经过分 9 步讲解
- **自来石**：关门、石条倒下顶门、"拐钉钥匙"推开的循环演示，配侧视受力图
- **为什么挖不进去**：深、藏、墙、门、撑、石六条防盗要点
- 着色、线条抖动、注记、自动旋转、视点复位

## 运行

纯静态页面，无需构建。Three.js 通过 import map 从 jsDelivr 加载。

```bash
npx serve dingling   # 或任意静态服务器
```

`index.html` 按 Claude Artifact 的页面格式书写（不含 `<!doctype>`/`<head>` 外壳），直接用浏览器打开也能运行。

## 资料依据

地宫尺寸（深约 27 m、总面积 1195 m²；前殿长 20、宽 6、高 7.2 m；后殿长 30.1、宽 9.1、高 9.5 m；配殿长 26、宽 6、高 7.1 m；石门每扇高 3.3、宽 1.7 m、约 4 t；金刚墙高 8.8、厚 1.6 m）取自公开的发掘报道与景区资料。隧道走向、甬道尺寸、宝城宝顶与明楼为示意。

## 代码结构

- `src/data.js` 尺寸、工程阶段、注记、导览与防盗讲解文本
- `src/materials.js` 排线着色器、抖动线条、剖面填充、生长/落块动画
- `src/builders.js` 石券、楔石、端墙、屋顶等参数化几何
- `src/scene.js` 组装整座陵墓，处理工程进度与门的开合
- `src/main.js` 渲染循环、剖切、注记、交互模式
