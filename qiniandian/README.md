# 祈年殿立体木构

用 Three.js 写的交互式"铅笔排线"构造图，展示天坛祈年殿：三层汉白玉台基、4 + 12 + 12 根大柱、枋梁、斗拱、三重檐、鎏金宝顶、天花与龙凤藻井、十二间槅扇。

## 功能

- **工程滑杆**：台基 → 栏杆台阶 → 立龙井柱 → 立金柱 → 立檐柱 → 枋梁 → 斗拱 → 下檐 → 中层鼓身 → 中檐 → 上层鼓身 → 上檐 → 宝顶 → 天花藻井 → 槅扇 → 着彩
- **剖切滑杆**：竖直剖面始终朝向观者，从台基外缘推到中轴
- **讲解文字开关**：播放工程时一律不显示讲解文字；也可以随时整体关闭
- **数柱子**：4 根龙井柱（四季）、12 根金柱（月）、12 根檐柱（时辰）、24（节气）、28（星宿）
- **不用大梁**：红线演示屋顶 → 斗拱 → 枋 → 柱 → 台基的受力路线，以及枋梁"箍桶"
- **历史变迁**：1420 大祀殿 → 1545 大享殿（上青中黄下绿）→ 1751 改蓝瓦更名祈年殿 → 1889 雷火焚毁 → 1896 重建完工
- **仰望藻井**：站在殿中央往上看

## 运行

纯静态页面，无需构建：`npx serve qiniandian`。

## 资料依据

台基三层共高 5.2 m，直径 68.2 / 79.3 / 90.3 m；殿高 31.6 m（连台基 36.8 m）；龙井柱高 19.2 m、直径 1.2 m；柱数与象征、历史年代取自公开资料。斗拱数量与尺寸、各层檐高、鼓身与藻井形制为示意。

`src/materials.js` 与 `src/builders.js` 与 `dingling/` 共用同一套排线渲染代码（各自一份，便于单独发布）。
